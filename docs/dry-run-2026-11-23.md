- **Live book mid 1,447.40 NGN/USDT** (Textile `USDT_NGN` ticker, 2026-11-23 12:15 UTC). The naira has moved since the Nov 4 dry run (mid 1,380.10 then).
- **Reference 1,367.64 NGN/USD** (open.er-api.com). Divergence from mid is about 5.8% (580 bps), under the 1,000 bps halt, so the guard stays open. The official-vs-market gap is real and expected.
- **Live preview: 10 USDT → 14,469.66 cNGN @ 1,446.97 NGN/USDT, fee 0.002 USDT, takerPays exactly 10 USDT.** The corridor quotes live at the demo size right now, with deep availability behind it.
- **Decision: halt.** The preview rate sits 3 bps below fair mid, so the firm edge (-3.03 bps) does not beat fee + gas + min edge (102 bps). The guard did its job: the agent refuses a conversion that pays under fair value. A preview is indicative, not a promise — in live mode the same check runs against the firm quote, and the run halts the same way if the firm price is under fair value. This is not a failure; it is the safety check working.
- **Wallet: 0 USDT, 0 CELO.** The agent wallet `0x77fBd73F31ab04334e7BF7a9027e08fc81686cE2` is unfunded, as expected. Inventory source is paper, and the log says so.
